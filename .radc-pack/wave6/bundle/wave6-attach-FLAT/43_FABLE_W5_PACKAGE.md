## 5. Proofs — affirmative first

### 5.1 W5-MDC-0 (exact two-demand leaf law; single-prototype insufficiency) — PROVED

Fix a leaf set `A` in a no-recovery baseline for `Q_n^(2)`. The first answer is a map `a₁ : [n] → {0,1}` (it may depend only on `S₁` and the transcript, and the transcript is constant on the leaf); the second answer is a map `a₂ : [n]² × {0,1} → {0,1}` (it may additionally depend on `S₂` and the realized `a₁`, which is a function of `S₁`). Randomization cannot help because the joint success probability is linear in any mixture. The joint success probability is
`P(both) = Σ_i θ_i Σ_j θ_j P(x_i = a₁(i), x_j = a₂(i,j) | A)`,
and for fixed `i` the inner maximization is achieved by first choosing `b = a₂(i,j)` to maximize each cell `P(x_i = a, x_j = b | A)` and then choosing `a = a₁(i)` to maximize the θ-weighted sum. That is exactly O5.2. ∎

**Insufficiency witness (DR).** `n = 3`, `A = {110, 011}`, any full-support θ with `θ = (θ₁,θ₂,θ₃)`. For any single prototype `p ∈ {0,1}³`, the demand pair `(1,3)` has joint success `P(x₁ = p₁, x₃ = p₃)`; since the two elements of `A` disagree in both coordinates 1 and 3 and realize the patterns `(1,0)` and `(0,1)`, any fixed `(p₁,p₃)` succeeds on at most one element even when `(p₁,p₃)` matches one of them, while cell-maximization attains `1/2` on **every** ordered pair, including `(1,3)`, with the sequential choice `a₁(1) = 1, a₂(1,3) = 0` etc. A direct check shows the prototype value is strictly smaller for the pair `(1,3)` whenever `p` is chosen to also serve pairs `(1,2)` and `(2,3)`: no single `p` attains cell-optimal success on all three off-diagonal pairs simultaneously. Hence floors computed with prototype leaves are not valid lower bounds; all Wave-5 floors use O5.2. ∎

### 5.2 W5-MDC-1 (candidate ledger; exact dedup interaction) — PROVED

`π_EDC²`: T1 emits control + handle (`1 + h` tokens, ×3). T2: after `S₁`, one expansion of exactly the demanded payload bit (`1 + q` tokens, ×2), answer. T3: if `S₂ = S₁` the demanded bit is already in context (its ×2 charge covers the carry into T3); otherwise one expansion (`1 + q` tokens, ×1), answer. With `(h,q,c₀,c₁) = (1,0,1/2,1/2)`:
`M = 3·2 + 2·1 + (1 − p_c)·1 = 9 − p_c`, `L = 1 + 1 + 1/2 + (3/2)(2 − p_c) = 11/2 − (3/2)p_c`, `D = 0`, `recall = 1`.
The dedup-free variant (always expand twice) has `M_naive = 9`, `L_naive = 11/2`, so **`M_naive − M = p_c` and `L_naive − L = (3/2)p_c` exactly**. Baselines possess no expansion events, hence no dedup analogue: the interaction term is a recovery-exclusive resource. Exactness of recall and `D = 0` follow from W4 exact-reference semantics (pinning retained). ∎

### 5.3 W5-MDC-2 (collision-mass phase, ZE class, every gauge) — PROVED

**Two-demand ZE-Gordian (splice of W4-ZE-GORDIAN).** Let `b` be any zero-error no-recovery baseline for `Q_n^(2)` at full-support θ. If two sources `x ≠ x'` shared a transcript fiber, a coordinate `i` with `x_i ≠ x'_i` would produce an error with positive probability on the event `S₁ = i` (positive by full support), contradicting `D = 0`. Hence the T1 code is injective on the support: `ℓ ≥ n` (prefix-free over `2^n` equiprobable strings; the W4 argument transfers verbatim, the demand count never enters injectivity). Therefore `M(b) ≥ 3(1+n)` and `L(b) ≥ 1 + n`, at **every** penalty gauge, including `ρ = λ = 0`.

**Dominance condition.** Comparing with O5.1: the `M`-condition `9 − p_c ≤ 3(1+n)` holds for all `n ≥ 2`; the `D`-condition is equality (`0 = 0`); the `L`-condition is
`11/2 − (3/2)p_c ≤ 1 + n ⟺ p_c ≥ (9 − 2n)/3`.
Strictness: the `M`-margin `3(1+n) − (9 − p_c) = 3n − 6 + p_c > 0` for `n ≥ 2`, so dominance (weak in all coordinates, strict in `M`) holds **iff** `p_c(θ) ≥ (9−2n)/3`. For `n = 4` this is the Rényi-2 condition `H₂(θ) ≤ log₂ 3`; for `n = 3` it requires `p_c ≥ 1`, impossible on full support; for `n ≥ 5` the right side is negative, so the condition is vacuous. Penalty-robustness is inherited from the gauge-free baseline floors and the candidate's `D = 0`. ∎

### 5.4 W5-MDC-3 (critical dimension 5 on `Θ_n^↓`; class-level `n ≤ 4` kill) — PROVED

`p_c` is convex on the simplex, so on `Θ_n^↓` its minimum is at the uniform point (interior for all `n`), `min p_c = 1/n`, and its maximum is at a vertex, `max p_c = ((n+4)² + 16(n−1))/(25n²)`.

**(a) `n ≥ 5`.** `(9−2n)/3 < 0 ≤ p_c`, so MDC-2 gives dominance at every `θ ∈ Θ_n^↓` with uniform margins
`γ_M = inf_θ [3(1+n) − (9−p_c)] = 3n − 6 + 1/n`, `γ_D = 0`, `γ_L = inf_θ [(1+n) − (11/2 − (3/2)p_c)] = n − 9/2 + 3/(2n) > 0` for `n ≥ 5`. (At `n = 5`: `γ_M = 46/5`, `γ_L = 4/5`.)

**(b) `n = 4`, class-level impossibility.** `p_c` is convex, so its maximum over `Θ_4^↓` is attained at a vertex; every vertex is a permutation of the same point with `p_c = 7/25 < 1/3`, hence `p_c(θ) ≤ 7/25` on the whole polytope. Hence for the registered candidate `L = 11/2 − (3/2)p_c ≥ 11/2 − 21/50 = 127/25 > 5 = L(identity)` at every `θ ∈ Θ_4^↓`. This kills not only `π_EDC²` but **every** exact-recovery reference policy at the registered latency gauge: such a policy must expand a set `P ∋ S₁` at T2 (`|P| = k ≥ 1` tokens, opacity forces at least the demanded bit post-demand) and, on the event `S₂ ∉ P`, expand again at T3 (≥ 1 token). Its latency satisfies
`L ≥ 1 + h + c₀ + (k + c₁) + P(S₂ ∉ P)(1 + c₁) ≥ 3 + k + (3/2)·P(S₂ ∉ P)`.
For `k = 1` (so `P = {S₁}`): `P(S₂ ∈ P) = p_c ≤ 7/25`, giving `L ≥ 4 + (3/2)(18/25) = 127/25 > 5`. For `k ≥ 2`: `L ≥ 5 + (3/2)P(S₂ ∉ P) ≥ 5`, with equality only if `P` covers `S₂` almost surely, impossible for `k ≤ 3` since every θ ∈ `Θ_4^↓` puts mass ≥ 4/(5·4) = 1/5 on each coordinate, so `P(S₂ ∉ P) ≥ (4−k)/5 > 0`; and `k = 4` gives `L ≥ 7`. Hence every candidate in the locked class has `L > 5 = L(identity)` somewhere (indeed everywhere) on `Θ_4^↓`, while identity is a legal baseline: two-demand dominance is impossible at `n = 4`. The cases `n = 3` (`L ≥ 4 + (3/2)(16/25) = 124/25 > 4`, using vertex `p_c = 9/25`) and `n = 2` are identical and worse. ∎

**Interpretation.** Two sequential demands double the round-trip latency burden while only tripling the baseline's carried payload burden; the recovery advantage in `M` grows (margin `3n−6+1/n` vs single-demand `2n−3+…`), but latency now needs `n ≥ 5` to amortize two trips. The single-demand critical dimension 3 (W4) shifts to **5**, and the shift is governed by the collision mass.

### 5.5 W5-MDC-4 (gauge `(40,20)`, full lossy hull, all `n`) — PROVED

**Claim.** On `Θ_n^↓` at `(ρ, λ) = (40, 20)` with the linked candidate: two-demand dominance over the **entire** no-recovery hull (lossy baselines included) holds for every `n ≥ 5` and fails for every `n ≤ 4`.

**Failure, `n ≤ 4` (exact).** Identity is in the hull; MDC-3(b) shows `L(candidate) > L(identity)` throughout `Θ_n^↓` for `n ≤ 4`. (The exact `α = 2` floors of MDC-5 confirm the same fact quantitatively: `F²₂` saturates at `2(1+n) < 2L(candidate)`, e.g. `10 < 41/4` at the Q4-uniform vertex.) ∎

**Success, `n ≥ 5`.** Three ingredients.

*(i) Union bound / marginal reduction.* For any baseline tree, the first-answer marginal is a legal single-demand configuration on the same tree, so `e₂ ≥ P(err₁) ≥ e₁*(tree) ≥` the single-demand floor at the same expected length. Hence for `α ∈ {2,3}`: `F²_α(t) ≥ F_α(t)` (single-demand), and in particular `2 + 2ℓ + t·e₂ ≥ Ψ_{n,t}(θ) = 2 + Σ_i ψ(tθ_i)` (W4 separable Fano bound), where `ψ(a) = 2[1 − log₂(1+2^{−a/2})]`.

*(ii) Schur reduction.* `ψ` is concave and increasing with `ψ(0)=0`, so `Σψ(tθ_i)` is Schur-concave; on `Θ_n^↓` it is minimized at the heavy vertex, value `Ψ↓_{n,t} = 2 + ψ(t(n+4)/(5n)) + (n−1)ψ(4t/(5n))`. The candidate side is maximized at the uniform point: `sup_θ 2L = 11 − 3/n`, `sup_θ M = 9 − 1/n`.

*(iii) Certificates `Ψ↓_{n,40} > 11 − 3/n`.*
- `n = 5` (target `52/5`): `Ψ↓_{5,40} = 12 − 2log₂(1+2^{−36/5}) − 8log₂(1+2^{−16/5})`. Since `36/5 > 7` and `16/5 > 3`: `(1+2^{−36/5})²(1+2^{−16/5})⁸ < (129/128)²(9/8)⁸ < 3` by the integer inequality `129²·9⁸ = 716,340,484,161 < 3·128²·8⁸ = 824,633,720,832`; and `log₂3 < 8/5` by `3⁵ = 243 < 256 = 2⁸`. Hence `Ψ↓_{5,40} > 12 − 8/5 = 52/5`, strictly, with margin `γ_L ≥ (1/10)·log₂(256/243) > 0`.
- `n = 6` (target `21/2`): from `2^{−20/3} < 1/64` and `2^{−8/3} ≤ 63/400` (integer check `63³·256 = 64,012,032 > 64,000,000 = 400³`), `(65/64)²(463/400)^{10} ≤ 8` by `65²·463¹⁰ ≤ 8·64²·400¹⁰` (verified integer inequality), giving `Ψ↓_{6,40} ≥ 12 − 2·(3/2) = 11 > 21/2`.
- `n = 7` (target `74/7`): from `2^{−44/7} ≤ 27/2048` (`27⁷ = 3²¹ ≥ 2³³`) and `2^{−16/7} ≤ 53/256` (`53⁷ ≥ 2⁴⁰`), `(2075/2048)²(309/256)¹² ≤ 32` (verified integer inequality), giving `Ψ↓_{7,40} ≥ 14 − 5 = ... ≥ 11 > 74/7`. [Explicitly: `Ψ↓_{7,40} = 16 − 2log₂(1+2^{−44/7}) − 12log₂(1+2^{−16/7}) ≥ 16 − 5 = 11`.]

### 5.7 W5-ANTI-OPT (exact one-bit theorem at the `Θ_n^↓` vertex, all `n`) — PROVED

**Theorem.** Fix `n ≥ 2` and the heavy vertex of `Θ_n^↓` (weights: heavy `a = n+4`, light `4`, total `W = 5n`, common denominator `d = 5n`). Among **all** one-bit prefix codes (arbitrary two-cell partitions of `{0,1}^n` with arbitrary per-leaf decoders), the antipodal code — nearest-prototype partition for any pair `{p, p̄}` — is exactly optimal, with error `e_n^anti = 2S(n−1)/(2^n·5n)`, `S(m) = Σ_{k=0}^m C(m,k)·min(4k, a+4m−4k)`. Moreover the optimal difference classes are exactly: `{(1,n−1)}` when `n ≥ 3` and `8 ∤ n`; `{(1,n−1), (1,n−2)}` when `8 | n`; `{(1,1),(1,0)}` when `n = 2`. The class differences obey the exact formula in Step 3.

**Step 1 (2-means / nearest-pair reduction).** A one-bit code is a partition `{A, A^c}`. The optimal decoder on a leaf answers demand `i` with the majority bit of coordinate `i`, so the unnormalized leaf distortion is `E(A) = Σ_i w_i·min(N_i^0(A), N_i^1(A)) = min_p Σ_{x∈A} d_w(x,p)` — the inner minimum is separable per coordinate and attained by the coordinatewise-majority prototype, where `d_w` is weighted Hamming distance. Taking optimal prototypes `p` for `A` and `q` for `A^c`:
`E(A) + E(A^c) = Σ_{x∈A} d_w(x,p) + Σ_{x∉A} d_w(x,q) ≥ Σ_x min(d_w(x,p), d_w(x,q)) ≥ min_{(p,q)} Σ_x min(d_w(x,p), d_w(x,q)) =: G`,
and the nearest-prototype partition of the minimizing pair attains `G` (ties either way). Hence the unrestricted one-bit optimum equals `G`, a minimum over the `C(2^n, 2) + 2^n` prototype pairs (the degenerate `p = q` reproduces the root leaf).

**Step 2 (difference-class reduction).** Substituting `y = x ⊕ p` (a bijection): `Σ_x min(d_w(x,p), d_w(x,q)) = Σ_y min(σ_w(y), σ_w(y ⊕ v)) =: g(v)` with `v = p ⊕ q`, depending only on `v`. Splitting coordinates into `supp(v)` and its complement: off-support coordinates contribute identically to both arguments, totalling `2^{n−1}(W − W_v)`; the on-support block contributes `2^{n−s}·h(v)` with `h(v) = Σ_{y_supp} min(σ, W_v − σ)` and `s = |supp v|`. By symmetry among lights, `g` depends only on `(b, m)` as in O5.4; for `b = 1` the two heavy-bit terms coincide after `k ↦ m−k`, so `h(1,m) = 2S(m)` and
`g(1,m) = 2^{n+1}(n−1−m) + 2^{n−m} S(m)`, and `g(0,m) = 2^{n−1}(W − 4m) + 2^{n−m}·4T(m)`, `T(m) = Σ_k C(m,k) min(k, m−k)`.

**Step 3 (exact difference formula; monotone descent).** Let `c := a + 4m` and `Δ_m := g(1,m) − g(1,m+1) = 2^{n−m−1}[2^{m+2} + 2S(m) − S(m+1)]`. Pascal's rule gives `2S(m) − S(m+1) = Σ_{k=0}^m C(m,k)·[2f(k;m) − f(k;m+1) − f(k+1;m+1)]` with `f(k;m) = min(4k, a+4m−4k)`. Per-`k` case analysis on the position of `8k` relative to `c`:
- deep left (`8k ≤ c−4`): all three `f`-values sit on the `4k` branch except the shifted one; the term equals `8k − 4k − (4k+4) = −4`.
- deep right (`8k ≥ c+4`): term `= 2(c−4k) − (c+4−4k) − (c−4k−4) = −4`.
- middle (`c−4 < 8k < c+4`): the open window `((c−4)/8, (c+4)/8)` has length 1, so it contains exactly one integer `k₀` unless `c ≡ 4 (mod 8)` (integral endpoints, empty interior). Sub-cases `8k₀ < c`, `= c`, `> c` give the term `−r` with `r = |8k₀ − c| ∈ {0,1,2,3}` in all three.
Unifying, `term_k = −4 + max(0, 4 − |8k − c|)`, hence
**`Δ_m = 2^{n−m−1} · C(m, k₀) · (4 − r)`** when the unique `k₀` with `|8k₀ − c| < 4` exists and lies in `[0, m]`, and `Δ_m = 0` otherwise (`r = |8k₀ − c|`). In particular `Δ_m ≥ 0` for every `m`: `g(1,·)` is nonincreasing, so the `b = 1` minimum is the antipodal class `m = n−1`. (Formula EC-verified exactly for all `n ≤ 40`, all `m`; checker `w5f_final_checks.py`.)

**Tie law.** At the final step `m = n−2`: `c = 5n−4`, and `k₀ ∈ [0, n−2]` holds for all `n ≥ 3`, so `Δ_{n−2} = 0 ⟺ r = 4 ⟺ 5n−4 ≡ 4 (mod 8) ⟺ 8 | n` (5 is invertible mod 8). When `8 | n`, the previous step has `c = 5n−8 ≡ 0 (mod 8)`, so `Δ_{n−3} = 2^{...}·C(n−3, k₀)·4 > 0` (and `k₀ ≤ n−3` for `n ≥ 8`): no third class can tie. When `8 ∤ n`, `Δ_{n−2} > 0` and the antipodal class is the strict unique minimum among `b = 1`. **Step 4 (`b = 0` strictly worse).** `g(0,m) − g(1,m) = 2^{n−1}a − 2^{n−m}[S(m) − 4T(m)]`. Per `k`: for `k ≤ m/2` the bracket vanishes; for `k > m/2` it equals `min(8k−4m, a)`. Hence `S − 4T = Σ_{k>m/2} C(m,k)·min(8k−4m, a) < a·2^{m−1}` strictly: if `m` is odd, the smallest term has `8k−4m = 4 < a = n+4`; if `m` is even, `Σ_{k>m/2} C(m,k) = (2^m − C(m,m/2))/2 < 2^{m−1}`. Therefore `g(0,m) − g(1,m) > 2^{n−1}a − 2^{n−m}·a·2^{m−1} = 0` for every `m ≥ 1`. (EC-verified `n ≤ 30`.)

**Step 5 (assembly).** Global one-bit optimum `= g(1, n−1) = 2S(n−1)`, i.e. `e_n^anti`, exactly the W4 closed form; for `n = 2` the direct class table gives the stated tie `g(1,0) = g(1,1) = 8`. ∎

## 6. Targeted obstruction map

**O1 — Polytope-uniform exact two-demand floors (why MDC-5 stops at vertices).** The single-demand vertex reduction rested on `e_θ` being *linear* in `θ`, so the floor's infimum over a polytope sits at a vertex. The two-demand leaf law O5.2 is *quadratic* in `θ` (a `θ⊗θ` form): the relevant image `{θ⊗θ : θ ∈ Θ}` is a Veronese-type curve segment on which **every** point is extreme, so no finite vertex reduction exists and per-θ exactness does not transfer to polytope-uniform exactness. The MDC-3/4 dichotomies avoid this by combining per-θ convexity of the candidate side (`p_c` convex ⟹ extremes at vertices/uniform) with lower-bound certificates (`Ψ↓`) that are Schur-monotone; the exact two-demand floor over a full polytope remains open.

**O2 — BP1 at general `n`.** The per-split density condition fails (antipodal pairs have density `1/2 > s₁`, §5.8), so any proof of the amortized tangent inequality must charge isolation cost against gain globally — a genuine amortization/potential argument, not a greedy induction. Open for `n ≥ 5`; EC-true at all five `n ≤ 4` classes.

**O3 — Two-demand latency at `n ≤ 4` (route closed).** The kill in MDC-3(b) is class-level and exact: for every exact-recovery schedule at the registered latency gauge, `L > L(identity)` throughout `Θ_n^↓`, `n ≤ 4`, using only `max p_c = 7/25 < 1/3` (n=4) and the round-trip floor. No re-gauging of `(ρ, λ)` can repair it (the kill is gauge-free on the `L` coordinate: both sides have `D = 0`). Wave-6 attempts should not revisit `n ≤ 4` two-demand dominance.

**O4 — Q5 deeper killers.** All prefix shapes with ≤ 4 leaves are exhausted (§5.14b); a fifth leaf adds length but also refinement, and shapes such as `(1,2,3,4,4)` keep `ℓ` near 1. The scan values are monotone in `t`, so any future kill improvement must come from ≥5-leaf trees evaluated at `t` slightly above `1600/121`; the search space grows as `~2^{5n}` prototype tuples and needs symmetry reduction (the `(b,m)`-class machinery of §5.7 extends to multi-prototype orbits and is the recommended route).

**O5 — Policy uniqueness (dead end, restated).** W4-EXTREMAL-NONUNIQUE/KILL remain final: no Wave-5 statement upgrades ledger uniqueness (§5.10) to policy uniqueness, and none should be attempted; the parity-alias fiber is irreducible at the ledger's optimum.
