## Integrity note (per tokenzero-bl6)

- Numbers are **medians**, not single-shot samples, to dampen scheduler jitter.
- `est_tokens` is a **coarse proxy** (`bytes / 4`), not a tokenizer-accurate
  count. Use it for relative ordering, not absolute billing.
- `output_bytes` reflects raw stdout only; stderr and tool-internal telemetry
  are excluded. Tools that emit structured JSON (TokenZero) will therefore show
  higher byte counts than tools that emit plain text — this is expected and
  should be normalised before drawing efficiency conclusions.
- Competitor availability varies by host. A skip is **not** a zero-cost result;
  do not impute values for absent tools.
- The benchmark does not modify the repository. Edit tasks operate on a
  temporary file under `/tmp` that is removed on exit.
- Re-run on the same host and same commit before publishing comparative claims.
  Do not compare numbers across different machines or Rust toolchain versions
  without recalibration.
