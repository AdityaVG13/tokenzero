## 1. Re-derived lock and definitions

Let Omega={0,1}^n, N=2^n, X uniform, and let integer demand weights w_i >= 0 have d=sum_i w_i. For A subset Omega, write N_i^b(A)=#{x in A:x_i=b} and

    E_w(A) = sum_i w_i min(N_i^0(A),N_i^1(A)).

For a recursive binary partition tree T with leaves A:

    E(T) = sum_leaf E_w(A),
    e(T) = E(T)/(dN),
    L(T) = sum_leaf |A| depth(A) = sum_internal |A|,
    ell(T) = L(T)/N,
    J_t(T) = 2 + 2 ell(T) + t e(T),
    F(t) = min_T J_t(T).

The root leaf has e=1/2 and J_0(t)=2+t/2. Let e1 be the minimum error over one-bit trees, s1=1/2-e1, and tau1=2/s1. Direct line comparison gives

    BP1 iff e(T) >= 1/2-s1 ell(T) for every T
        iff G(T):=E_w(Omega)-E(T) <= s1 d L(T) for every T
        iff the root is optimal in the scalar DP at t=tau1.

A one-bit optimizer has ell=1 and meets the root at tau1, so this equivalence is exact. This re-attests W5-BP1 and the W6 restatements.

## 3. New theorem: uniform BP1 through n=12

### W7-SOL-BP1-UNIFORM-SIZE-DP [DR]

At uniform demand define

    Phi(A)=sum_i |sum_{x in A} (-1)^(x_i)|.

Then E(A)=(n|A|-Phi(A))/2. Let beta_n(k)=max_{|A|=k} Phi(A). The exact Kimi identity re-derives as follows:

    Phi(A)=max_{sigma in {+1,-1}^n} sum_{x in A} <sigma,(-1)^x>.

For fixed |A|=k, choose the k largest scores. Every sigma has the same multiset

    q_n = {n-2j repeated C(n,j) times, j=0,...,n}.

Thus beta_n(k) is exactly the sum of the k largest q_n values. Put M_n=max_k beta_n(k)=beta_n's positive-score sum and c_n=M_n/N. This also gives e1=1/2-M_n/(nN).

Sufficient size certificate: for all positive a,b with a+b<=N, require

    D_n(a,b) := 2 M_n(a+b) + N beta_n(a+b)
                - N beta_n(a) - N beta_n(b) >= 0.                 (C)

Proof. For any subtree rooted on a cell A of size k, define

    H(T_A)=sum_{leaf C below A} Phi(C)-2c_n L(T_A).

At a leaf, H=Phi(A)<=beta_n(k). If A splits into sizes a,b, induction and (C) give

    H(T_A)<=beta_n(a)+beta_n(b)-2c_n(a+b)<=beta_n(k).

At Omega, beta_n(N)=0, hence sum_leaf Phi<=2c_n L. Therefore

    e(T)=1/2-sum_leaf Phi/(2nN)
        >=1/2-[M_n/(nN)] [L/N]
        =1/2-s1 ell(T).

So (C) proves BP1 without enumerating any source subset or tree. This is a relaxation: child cells are allowed to attain beta independently, so passing it is stronger than the required tree inequality.

For a cell C define the exact cell DP

    U_c(C)=min(E(C), min_{B disjoint D=C} c|C|+U_c(B)+U_c(D)).

In integer scaling S=32,K=158, U_c(C)=32E(C) means that every subtree under C has nonpositive excess R(C)=max[G_C-cL_C]. For root split B,C, set

    gamma=E0-E(B)-E(C),  slack=cN-gamma=158-gamma.

If R(B)+R(C)<=slack, every tree under that root satisfies the BP1 tangent.

## 5. All-n survivors and infinite obstructions

### W7-SOL-BP1-ALLN-BASE4 [DR]

For arbitrary nonnegative weights, the W6 bias induction gives

    sum_leaf Phi_w(A) <= d L(T),
    e(T) >= 1/2-ell(T)/2.

Hence F(t)=2+t/2 on 0<=t<=4 for every n and demand class. This is a lower bound on the first breakpoint, not BP1 unless the one-bit candidate equals 4.

### W7-SOL-BP1-ANTI-LOCAL-OBSTRUCTION [DR]

For every full-support class and n>=2, an antipodal pair A={x,bar x} has E(A)=d and splitting it into singletons gains d, so its normalized split-gain density is exactly 1/2. Since e1>0, s1<1/2. Therefore any proof demanding local gain density <=s1 at every split fails for infinitely many n and for 2^(n-1) cells at each n. This blocks only edgewise greedy induction, not BP1.

### W7-SOL-BP1-LEAF-INFO-OBSTRUCTION [DR]

At the heavy vertex v_n=((n+4),4,...,4)/(5n), take A=Omega minus one point. Its posterior advantage is 1/[2(N-1)], so advantage divided by self-information is

    R_n = 1 / [2(N-1) log2(N/(N-1))] > ln(2)/2 > 1/3.

Fourier Cauchy-Parseval gives s1<=||v_n||_2/2 with ||v_n||_2^2=(n+24)/(25n), hence s1<=3/10<1/3 for n>=3. Thus the pointwise leaf budget advantage<=s1 log2(N/|A|) fails for every n>=3. This blocks leafwise self-information charging, not sibling-coupled or global potentials.

A corrected trivial depth fragment is also exact: if every leaf has depth at least r, then G/(dL)<=1/(2r). It certifies such trees only when s1>=1/(2r). For Q5-down, r=3 works because 1/6<79/400; r=2 does not follow from this bound.
